# Aurora IPTV

Aurora IPTV is a desktop toolkit for working with your own IPTV playlists and
server details. It keeps list analysis, checking, export and archive tools in
one local application.

![Main window](docs/screenshots/main-window.png)

## Highlights

- Open and organize M3U playlists and server details you are authorized to use.
- Check and export playlist information.
- Keep local archives and work with Stalker-compatible details where permitted.
- Built with Python and PyQt6.

## Run from source

```bash
python3 main.py
```

Install dependencies first:

```bash
python3 -m pip install -r requirements.txt
```
